## 4. Layout structure notes

- **Not a full-bleed photo hero.** Soft teal gradient background (`#fff → #f7fbfb → #e6f5f6`), 2-column flex (~500px copy / ~430px media), max-width 1200px.
- **Hero media column** stacks exterior photo + two promo/info cards (CDCP + Ortho).
- **Appointment section:** light teal page bg (`#f7fbfb`), centered header, **2fr / 1fr grid** — JotForm card left, offer card right; stacks to 1 column ≤900px.
- **Trust + Featured:** card grids with soft shadows, rounded corners (~22–28px), no interaction cards (no links on featured services).
- **Booking:** white rounded container card on `#f7fbfb`, embedded RecallMax iframe.
- **Consultation banner:** full-width cover background image + text CTA (site chrome pattern).
- Theme chrome (notification + sticky white nav + dark footer) wraps the custom landing blocks.

- Landing blocks: **Arial, Helvetica, sans-serif** (inline)
- Theme: **Roboto**, **acumin-pro-condensed** / **acumin-pro-semi-condensed**
- H1: clamp(40px, 5vw, 66px), weight 800, letter-spacing -1px
- Section H2: ~clamp(34–56px), weight 800
- Feature H3: 24px / 700
- Body: ~18–20px, line-height ~1.7
- Eyebrows: 14–15px, uppercase, letter-spacing 1px, `#008991`, weight 700

### Components

- Primary button: pill (`border-radius: 999px`), `#008991` bg, white text, soft teal shadow
- Secondary button: white bg, `#008991` 2px border, teal text, same pill height 58px

- Cards: 18–28px radius, `box-shadow: 0 15px 40–45px rgba(0,0,0,.08)`
